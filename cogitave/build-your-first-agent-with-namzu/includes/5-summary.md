You built your first agent with the Namzu kernel and ran it on the Yuva operating system.

- Distinguished the **Namzu** kernel (TypeScript, build-time) from the **Yuva** operating system (Rust, serve-time).
- Built a minimal MCP-native agent with one **tool** and one **resource**.
- Declared the agent's **identity, capabilities, and boundaries** as a least-privilege allow-list.
- Served the agent over `stdio` and Streamable HTTP, and gated it with **evals**.
