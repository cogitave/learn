Agents need an operating system. **Yuva** is that operating system — *not for humans, only for agents*. It manages identity, capabilities, isolation, and the runtime surface that agents execute against, while the **Namzu** kernel provides the lower-level primitives the agent layer is built on.

In this module, you'll learn what Yuva is, how it relates to Namzu, and run your first agent.
